# DataSalud Perú
Proyecto final del curso Base de Datos Avanzadas y Big Data.

## Archivos del repositorio
- `PROYECTO (BD).sql`
  Contiene la implementación de la base de datos operacional, procedimientos almacenados, triggers, funciones, auditoría y componentes de seguridad.

- `PROYECTO (DW).sql`
  Contiene la creación del Data Warehouse, dimensiones, tabla de hechos y proceso ETL.

- `Anexo07_Vistas_KPI_OLAP.sql`
  Contiene las vistas SQL utilizadas para el cálculo de los KPIs, operaciones OLAP y consultas de gobernanza.

- `DIRESA_NoSQL.Atenciones_Semiestructuradas.json`
  Contiene registros semiestructurados utilizados como evidencia de la integración con MongoDB.

## Tecnologías utilizadas
- SQL Server
- MongoDB
- Power BI Desktop
- Apache Spark / PySpark
- Google Colab

## Proyecto
El proyecto propone una arquitectura integrada para la gestión, validación, análisis y visualización de información nutricional de la DIRESA La Libertad.

La solución integra una base de datos operacional, un Data Warehouse bajo esquema estrella, procesamiento NoSQL, análisis OLAP, KPIs en SQL Server, visualización mediante Power BI y análisis de escalabilidad mediante Apache Spark.
